Flight Status API

Aggregates real-time flight data from multiple providers (AeroTrack & QuickFlight) and returns the most recently updated status.

Available Endpoints
GET /flights/status
Returns the merged flight status from all configured providers.
flightNumber — IATA flight code (e.g. BA493)  ·  date — Flight date in yyyy-MM-dd format
GET /health
Returns API health status and current UTC time.
Try it
GET /flights/status?flightNumber=BA493&date=2025-08-15
